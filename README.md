# Payoo Mobile Banking

**Payoo-mobile-banking** is a web-based mobile banking application interface developed as a front-end prototype. It utilizes modern web technologies to provide a streamlined and responsive financial user experience [1, 2].

## 🚀 Tech Stack

*   **HTML5 (55.7%):** Used for the structure of the banking interface [2].
*   **JavaScript (44.3%):** Powers the client-side logic and interactivity [2].
*   **Tailwind CSS:** Integrated via `tailwind.config.js` for utility-first, responsive styling [1].

## 📁 Project Structure

The repository is organized into the following directories and files [1]:

*   **`.vscode/`**: Contains project-specific settings for the Visual Studio Code editor.
*   **`assets/`**: Contains static resources such as images or icons.
*   **`script/`**: Houses the JavaScript files for the application's logic.
*   **`index.html`**: The main entry point of the application (login/landing page).
*   **`home.html`**: The main dashboard or home screen for the banking interface.
*   **`tailwind.config.js`**: Configuration file for Tailwind CSS styling.

## 🛠️ Getting Started

To view or work on this project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/rabbitkg/Payoo-mobile-banking.git
    ```
2.  **Open the project:**
    Open `index.html` in any modern web browser to view the application [1].
3.  **Development:**
    Ensure you use a live server (like the VS Code Live Server extension) or have a method to compile Tailwind CSS if you intend to modify the utility styles [1].
